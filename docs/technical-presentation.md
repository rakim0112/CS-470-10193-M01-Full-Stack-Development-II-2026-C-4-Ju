# Technical Presentation Notes

## Project

CS-470 Full Stack Development II — Cloud-Based Full-Stack Application

## Audience

Technical and non-technical stakeholders who need a clear explanation of how the application works and why cloud deployment was used.

## Presentation Structure

1. **Problem and Purpose** — Explain the application and the users it serves.
2. **Existing Full-Stack Foundation** — Connect the project to CS-465.
3. **Architecture** — Explain the Angular frontend, Node.js/Express API, and MongoDB database.
4. **Cloud Migration** — Explain Docker, AWS S3, AWS Lambda, and CORS.
5. **Challenges** — Discuss compatibility, build, container, and deployment issues.
6. **Testing** — Explain how the application was verified across its major layers.
7. **Security** — Discuss credentials, CORS, permissions, and environment configuration.
8. **Results and Future Work** — Explain what was accomplished and what would be improved in a production system.

## Key Career Message

This project demonstrates that I can work across frontend and backend development while also understanding the infrastructure and deployment concerns that affect a cloud-hosted application. It gives me a practical foundation for junior full-stack, backend, and cloud-development roles.
