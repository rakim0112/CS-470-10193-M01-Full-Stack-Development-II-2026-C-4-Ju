# CS-470 Project Overview

## Purpose

CS-470 Full Stack Development II extends the full-stack application developed in CS-465. The focus of this course was moving the application toward a cloud deployment model while applying cloud development principles and best practices.

## Application Layers

The project is organized around three primary application responsibilities:

1. **Frontend** — Angular provides the client-facing application and administration interface.
2. **Backend** — Node.js and Express provide REST API functionality and application logic.
3. **Database** — MongoDB stores application data accessed through the backend.

## Cloud and Infrastructure Work

The project introduced AWS services and Docker-based development into the application workflow. The frontend build was prepared for S3 deployment, while AWS Lambda and CORS were used as part of the cloud/API work.

## Development Challenges

The project included practical troubleshooting around Node.js versions, Angular CLI/build tooling, dependency installation, Docker containers, Docker Compose, networking, and AWS configuration. Working through these issues reinforced the importance of reproducible environments, version compatibility, incremental testing, and careful configuration management.

## Career Relevance

The project demonstrates practical skills applicable to junior full-stack, backend, cloud, and software-development roles. It shows experience working across an application rather than focusing on a single programming language or layer.
